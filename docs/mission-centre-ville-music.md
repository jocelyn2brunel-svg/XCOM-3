# Musique procédurale globale

- Implémentation: génération procédurale en code (aucun fichier audio binaire ajouté au dépôt).
- Style: jazz-fusion / acid jazz (groove syncopé, electric piano, clavinet, basse ronde), avec une légère texture analogique.
- Boucle: motif de 12 secondes régénéré dynamiquement selon le niveau d'ambiance.
- Raffinement: progression harmonique étendue sur 16 mesures, accents de 7e/9e/11e, hi-hat shuffle, ghost notes de caisse claire, pulse syncopé et sidechain plus léger pour conserver le swing.
- Portée: utilisée partout (menu principal + toutes les missions), sans fallback vers les MP3 du dépôt.
